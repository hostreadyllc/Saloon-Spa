# Salon Ledger for Android

The Salon & Spa Ledger web app packaged as an Android app with Capacitor.

- `www/` – the app itself (same as the web version)
- `android/` – the Android project
- `.github/workflows/build-apk.yml` – builds a signed APK on every push to `main` and publishes it under **Releases**

To get the latest APK, open the repository's **Releases** page and download the `.apk` file.

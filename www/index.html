Connect your database

This is a one-time step on each device. Your records are kept in your own Supabase project, so every PC, phone and tablet sees the same data.

  1. Open your project at supabase.com
  2. Go to Project Settings, then API
  3. Copy the Project URL and the anon public key

Tip: once one device is set up, use Settings, then Copy setup link, to set up the others in one tap.
